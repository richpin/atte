# Domain docs

단일 컨텍스트 구조를 사용한다.

## 탐색 전 읽기

- 저장소 루트의 `CONTEXT.md`
- 작업 영역과 관련된 `docs/adr/`의 ADR

없는 문서는 건너뛴다. 빈 문서나 ADR을 미리 만들지 않는다.
용어와 결정이 확정될 때 domain-modeling 스킬로 작성한다.

## 사용 규칙

명세, 작업, 테스트에서 도메인 개념을 지칭할 때 CONTEXT.md의 용어와 정의를 따른다.

필요한 용어가 없다면 기존 용어로 표현 가능한지 먼저 확인하고,
실제 공백이면 domain-modeling의 검토 대상으로 남긴다.

기존 ADR과 충돌하는 제안은 해당 ADR과 충돌 이유를 명시한다.
