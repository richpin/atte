# 도구 결과 표시

연속된 Thinking과 도구 호출은 1개부터 하나의 작업 과정(Work log)으로 묶는다. 생성 중인 마지막 구간은 기존 항목을 그대로 쌓아 표시하고, 다른 응답 유형이 오거나 응답이 종료되면 `작업 과정 · N개`(영어: `Work log · N items`, 1개는 `1 item`) 한 줄로 접는다. 실패·중단 상태는 이 줄에 표시하지 않는다. 턴 사이에는 묶지 않는다.

생성 중 상세를 펼쳤어도 구간 종료 시 바깥 그룹은 자동으로 접힌다. 이후 사용자가 펼치면 내부 항목의 펼침 상태를 유지하며, 결과 갱신 때문에 다시 접히지 않는다. 해당 구간의 도구에 승인·질문 요청이 대기 중이면 항목을 노출하고 요청이 해소된 뒤 접는다. 과거 기록은 접힌 상태로 시작하며, 접힌 그룹 내부는 검색에서 제외한다. 펼침 상태는 화면에서만 관리한다.

그룹이 노출된 동안 도구 호출은 기본적으로 접힌 제목과 실행 상태를 표시한다. 이미지·오디오 등 콘텐츠 미리보기는 접힌 상태에서도 유지한다.

입력값·원시 결과·텍스트 결과·파일 링크(`resource_link`)·파일 위치·diff 및 terminal 안내는 펼친 상세 영역에서만 표시한다. 미리보기와 파일 링크가 함께 반환되어도 파일 링크는 상세 영역에 둔다. 이미지 MIME 타입을 가진 파일 링크도 같은 규칙을 따른다.
