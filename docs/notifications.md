# 데스크톱 알림

macOS에서 Atte를 사용하지 않을 때 응답 완료와 승인·질문 요청을 알린다. 앱이 비활성이거나 메인 창이 숨겨지거나 최소화된 상태를 대상으로 한다. 자식 웹뷰 간 포커스 이동은 앱 이탈이 아니다. 창 닫기는 창을 숨기므로 실행과 알림 상태를 유지한다.

## 발생과 확인

- 정상 응답 완료 시 알린다. 대기 메시지가 자동으로 이어지는 중간 완료, 취소, 실행 실패, 연결 끊김은 알림을 만들지 않는다. 일반 답변의 질문은 응답 완료로 다루고, Form Elicitation은 미해소 응답 요청으로 다룬다.
- 응답 대기에 진입할 때 한 번 알린다. 같은 대기 중 추가 요청은 재알림하지 않으며 모두 해소된 뒤 새 응답 대기에 진입하면 다시 알린다.
- 활성 중 발생한 사건은 앱을 떠나도 소급해서 알리지 않는다. 발행 시 활성 여부를 목록 이벤트와 함께 캡처해 비동기 처리 중 포커스가 바뀌어도 대상이 바뀌지 않게 한다.
- Dock 숫자는 비활성 중 발생한 미확인 완료 또는 미해소 응답 대기가 있는 스레드 수다. 한 스레드는 한 번만 세고 0이면 배지를 제거한다.
- 활성 상태에서 해당 스레드 페이지를 열면 완료를 확인한다. 스크롤 위치는 무관하며 다른 스레드나 설정 화면에서는 확인하지 않는다. 앱 복귀만으로 다른 스레드의 배지를 지우지 않는다.
- 승인·질문 요청은 페이지를 열어도 유지하며 모든 요청의 응답·취소·무효화 시 해제한다. 스레드 삭제도 관련 상태를 제거한다.

알림에는 스레드 제목과 앱 표시 언어의 사건 종류만 제공하고 대화 본문·도구 명령·질문 본문·답변을 넣지 않는다. 기본 알림음을 요청하되 표시·소리·집중 모드는 macOS 설정을 따른다. 클릭하면 창을 복원·활성화하고 해당 스레드를 연다. 직접 승인 동작은 제공하지 않는다. 확인한 완료와 해소된 승인·질문 요청의 OS 알림은 자동 제거한다. 사용자가 알림을 닫는 것은 확인이나 요청 응답이 아니다.

## 설정과 수명

첫 UI 준비 후 OS 권한이 미결정이면 알림 권한을 요청한다. 거부된 권한은 반복 요청하지 않는다. 일반 설정은 완료·승인 및 질문 알림 스위치, 실제 OS 권한 상태, macOS 알림 설정 이동 버튼을 제공한다. 두 스위치는 기본으로 켜져 있고 OS 알림만 제어한다. 끄면 해당 종류의 기존 OS 알림을 제거하지만 Dock 상태는 유지한다. 다시 켜거나 권한을 허용해도 과거 사건을 재발송하지 않는다.

승인 및 질문 알림은 기존 `permission` 설정 키를 함께 사용한다.

두 스위치는 앱 데이터 폴더의 `notification-preferences.json`에 저장한다. 완료 확인과 Dock 대상은 메모리에만 보관하며 DB에는 저장하지 않는다. 완전 종료·재시작 시 배지와 이전 OS 알림을 정리하고 과거 완료를 복원하지 않는다. 알림 전달·설정 오류는 에이전트 실행을 막지 않으며 설정 화면과 로그로 안내한다.

## 구현 경계

Rust 정책 모듈은 스레드 목록 구독의 완료 ID와 실행 상태를 관찰한다. 스레드 잠금 안에서는 이벤트의 활성 여부만 캡처하고 OS 호출은 하지 않는다. 정책 변경과 OS 효과는 메인 스레드에서 직렬화한다. 발송 직전과 비동기 제출 완료 후 유효성을 재확인해 확인·삭제·설정 변경과 경합한 알림이 남지 않게 한다.

macOS 구현은 `objc2-user-notifications`의 UserNotifications로 권한·발송·클릭·제거를 처리한다. Tauri의 Dock 배지 API와 기존 창 복원 경로를 재사용하며 Tauri의 AppKit delegate를 교체하지 않는다. 일반 Tauri 알림 플러그인은 macOS 실제 권한 조회와 표시한 알림 제거를 지원하지 않아 사용하지 않는다. UserNotifications는 macOS 10.14 이상과 서명된 앱 번들이 필요하다. 로컬 번들은 Tauri의 ad-hoc 서명(`signingIdentity: "-"`)을 사용하며 배포 시 `APPLE_SIGNING_IDENTITY`로 배포 인증서를 지정할 수 있다. 시스템 연동 검증에는 `.app` 빌드를 사용한다. 번들 없는 개발 실행에서는 설정에 제한을 표시하고 앱 기능과 Dock 처리는 유지한다.

프런트엔드는 알림 상태 구독을 단일 공급원으로 사용하고 현재 페이지·표시 언어를 보고한다. 클릭 이동 요청은 UI가 처리한 ID를 확인할 때까지 보존한다. 앱 명령은 신뢰된 `main` 웹뷰에만 허용하고 원격 웹뷰에는 권한을 추가하지 않는다. macOS 외 플랫폼은 시스템 알림을 추가하지 않으며 기존 완료 확인 동작을 유지한다.
