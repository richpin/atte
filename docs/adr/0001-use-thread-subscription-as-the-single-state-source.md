# 스레드 상태는 구독을 단일 공급원으로 사용한다

스레드의 공개 상태는 백엔드 구독의 초기 스냅샷과 이후 변경으로만 구성한다. 메시지 전송·중단·승인·질문 응답·설정 변경 등의 명령은 성공 또는 실패를 반환하고, 필요한 생성 명령만 새 ID를 반환한다. 명령 결과와 구독을 각각 상태 공급원으로 병합하면 순서 경합이 생기므로 이 경계를 유지한다.

구독이 끊기면 마지막 표시 내용과 작성 중인 입력은 보존하되 상태를 바꾸는 명령은 구독 복구까지 막는다. 구독 복구와 에이전트 세션 재연결은 별개다. 오래된 에이전트 이벤트는 연결 generation으로 거부하고, 새 구독의 스냅샷을 받으면 화면 상태를 다시 맞춘다.

승인·질문 요청은 스레드의 미해소 상호작용으로 관리하고 `waitingForInput`은 그 요청에서 도출한다. 응답·취소·연결 종료 시 소유 요청을 해소하며 오래된 요청을 재시작 뒤 재생하지 않는다. 미전송 입력과 스레드 정보의 저장 범위는 [DB 문서](../database.md)를 따른다.
