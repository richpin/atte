# Use ACP config options for thread configuration

Atte는 모델·추론 수준·동작 모드를 에이전트별 필드로 정의하지 않고, 에이전트가 ACP v1 `configOptions`로 제공한 `select`와 `boolean` 설정을 범용적으로 표시한다. Category는 배치 힌트로만 사용하며, 이번 범위에서는 deprecated `modes` fallback, 설정 기본값 저장, 설정 이름을 근거로 한 Atte 자체의 자동 승인 정책을 제공하지 않는다. 사용자의 선택은 프롬프트 전송까지 보류하지 않고 즉시 적용하며, UI에는 pending 상태를 따로 노출하지 않고 선택값을 곧바로 표시한다. 같은 표시값의 선택은 요청하지 않고, 연속 변경 중에도 다른 control은 계속 사용할 수 있게 하되 스레드별 요청을 직렬화하고 아직 전송하지 않은 동일 설정은 마지막 선택으로 합친다. 각 응답에서는 에이전트가 반환한 전체 option snapshot을 반영하고 다음 선택의 유효성을 다시 검사한다. 설정 변경 실패는 스레드 실패로 확대하지 않고 마지막으로 확인된 snapshot으로 되돌리며, 연결 중에는 이전 설정을 현재값처럼 표시하지 않는다. 이렇게 하면 Atte가 확실히 지원할 수 있다고 에이전트가 광고한 설정만 노출하면서 종속된 옵션의 변화도 그대로 수용할 수 있다.
