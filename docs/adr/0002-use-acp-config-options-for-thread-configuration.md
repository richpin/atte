# 스레드 설정은 ACP config options를 따른다

모델·추론 수준·동작 모드 등을 에이전트별 필드로 고정하면 새 에이전트의 설정을 잃거나 잘못 해석할 수 있다. Atte는 ACP v1 `configOptions`의 지원되는 `select`·`boolean` 설정을 이름·순서·값 그대로 표시하고, 변경 응답의 전체 스냅샷을 다시 확인한다. 설정 변경 실패는 마지막 확인 상태로 되돌리며 스레드 자체를 실패시키지 않는다.

같은 에이전트의 새 스레드에는 이번 앱 실행에서 사용자가 마지막으로 성공적으로 변경한 설정값을 메모리에서 적용한다. 복원한 스레드는 에이전트가 반환한 설정을 따르고, 이 기본값을 영구 저장하지 않는다. 설정 이름으로 권한 정책을 추측하거나 deprecated `modes`를 별도 설정 체계로 사용하지 않는다.
