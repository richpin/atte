# ACP Registry agent icons

The SVG files in this directory were downloaded on 2026-09-24 from the
[ACP Registry distribution](https://cdn.agentclientprotocol.com/registry/v1/latest/registry.json).
Each filename is the Registry agent ID and was downloaded from that entry's
`icon` URL.

The Registry source repository is
[`agentclientprotocol/registry`](https://github.com/agentclientprotocol/registry).
The Registry code and metadata are Apache-2.0, while agent names, logos, and
other marks remain subject to their respective owners' terms.
