# Open working folder

스레드 헤더의 오른쪽 메뉴에서 Reconnect 바로 아래에 다음으로 열기(Open in) 서브메뉴를 제공한다. 현재 스레드의 작업 폴더 또는 프로젝트 문서를 선택한 앱으로 열며 에이전트 연결 상태와 무관하게 동작한다. macOS에서만 표시한다.

## Native discovery

지원 앱 이름·bundle ID 목록을 코드에 유지하지 않는다. NSWorkspace.URLsForApplicationsToOpenURL로 해당 컴퓨터에서 열 대상을 처리할 수 있는 앱을 조회하고 OS가 반환하는 적합도 순서를 유지한다. 앱 이름은 OS의 현지화된 표시 이름을 사용한다. 목록에는 OS에 해당 형식을 처리한다고 등록된 앱이 표시되므로 코딩 에디터 이외의 앱도 포함될 수 있다.

작업 폴더의 바로 아래에서 .xcworkspace 디렉터리를 우선 찾고, 없으면 .xcodeproj 디렉터리를 찾는다. 중첩 폴더나 프로젝트 내부를 재귀 탐색하지 않으며 프로젝트 심볼릭 링크를 따라가지 않는다. 작업 폴더 자체가 프로젝트 번들이면 그 번들을 그대로 조회한다. 여러 프로젝트 문서는 파일명 순서로 제공하고 앱 이름 옆에 파일명을 표시해 사용자가 선택하도록 한다.

프로젝트 문서를 처리하는 앱과 작업 폴더를 처리하는 앱을 합쳐 제공한다. 같은 앱이 둘 다 처리하면 프로젝트 문서를 여는 항목을 우선하고 중복 폴더 항목은 생략한다. 프로젝트가 없으면 폴더를 기준으로만 조회한다. Finder를 포함한 앱 목록은 OS 결과를 따르며 별도 고정 항목을 추가하지 않는다.

## UI

메뉴를 열거나 선택 스레드가 바뀔 때 앱과 아이콘을 다시 조회한다. 이전 스레드의 비동기 조회 결과를 새 스레드에 표시하지 않는다. 조회 중에는 로딩, 실패하면 메뉴를 유지하는 재시도 항목, 결과가 없으면 비활성 안내 항목을 표시한다.

각 항목 왼쪽에 설치된 앱의 실제 아이콘을 표시한다. NSWorkspace에서 추출한 32×32 PNG를 16px로 표시하며 라이트·다크 테마에서 원래 색상을 유지한다. 아이콘 추출이나 이미지 로딩 실패 시 일반 앱 아이콘을 표시한다. 앱 이름을 접근성 레이블로 사용하며 아이콘은 장식 요소다.

프런트엔드 기능은 features/open-working-folder에 위치한다. 기존 Kobalte 메뉴와 Image를 사용하고 서브메뉴는 Portal로 렌더링한다. 메뉴 이동과 선택은 Kobalte의 키보드 동작을 유지한다.

## Commands

list_working_folder_apps는 threadId를 받아 { id, name, icon } 목록을 반환한다. icon은 PNG data URL 또는 null이고 id는 앱과 열 대상의 조합을 식별하는 불투명 문자열이다. open_working_folder는 threadId와 이 id를 target으로 받는다.

Rust가 스레드의 작업 폴더를 조회하고 실행 직전에 열 대상과 OS 앱 목록을 다시 확인한다. 현재 조회 결과에 없는 임의 앱·문서 조합은 거부하며 프런트엔드의 경로 문자열을 실행 권한으로 신뢰하지 않는다. 파일 탐색과 실행은 블로킹 작업으로 분리하고 AppKit 작업은 메인 스레드에서 수행한다. OS 실행 중 스레드 상태 잠금을 유지하지 않는다. 폴더 없음, 앱 연결 없음, 스레드 없음, 조회 실패, 실행 실패를 구분하고 한국어·영어 메시지를 제공한다.

DB와 CSP는 변경하지 않는다. 수동 앱 등록, 기본 앱 변경, 재귀 프로젝트 탐색은 포함하지 않는다.
