# 스레드 진행을 차단하는 컴팩트 Sign-in Dialog

## Problem Statement

에이전트 인증이 필요하면 스레드 페이지에서 인증을 완료하도록 안내한다. 입력창에 별도의 Sign in 진입 버튼을 두지 않고, 자동으로 열리는 작은 modal Dialog로 스레드 조작을 차단한다. 작성 중인 메시지와 첨부는 유지한다.

## Current UI/UX

- 활성 스레드에 인증이 필요하면 공통 Dialog가 자동으로 열린다. 화면 재진입 시에도 인증이 필요하면 다시 표시한다.
- 입력창에는 인증 안내, 로그인 방법 목록, Sign in 버튼을 두지 않는다. 입력창 자체와 초안·첨부는 Dialog 뒤에 유지하며 modal 동안 사용자 조작을 차단한다.
- Dialog에 닫기 버튼을 표시하지 않는다. Escape, 외부 클릭 및 외부 포커스 이동으로 닫히지 않는다.
- 사용자가 인증 방법을 선택해야 인증을 시작한다. 인증 방법이 하나여도 자동으로 시작하지 않는다.
- 로그인 취소는 기존 취소 API를 호출하고 Dialog 안에서 방법 선택으로 돌아간다. 취소 처리 중 새 인증을 차단하며 늦은 완료 결과를 무시한다.
- 조회 중, 지원되는 방법 없음, 조회·로그인 오류, 재시도, 브라우저/터미널 안내, 인증 진행, 취소 진행을 모두 Dialog 안에서 표시한다. 같은 오류를 중복 통지하지 않는다.
- 지원되는 인증 방법만 제공 순서대로 표시하고 제공된 이름·설명을 사용한다. 과금 정책을 추정하거나 Claude 방법을 고정하지 않는다.
- Dialog는 최대 폭 420px, 여백 24px, 행 최소 높이 약 64px, 간격 8px을 사용한다. 행 전체를 키보드로 접근 가능한 중립적인 버튼으로 표시하며 긴 이름·설명은 줄바꿈한다.
- 다른 스레드나 페이지로 외부 탐색이 발생하면 이전 화면의 Dialog 및 포커스를 복원하지 않는다. 화면 이동으로 에이전트별 인증을 취소하지 않는다.
- 인증 후 현재 선택된 시작 스레드를 한 번 재연결한다. 다른 스레드를 자동으로 재연결하지 않고 시작 스레드로 돌아왔을 때 재연결하는 기존 규칙을 유지한다.
- 인증 완료 후 재연결 진행을 표시하고 구독이 준비 완료를 전달한 뒤 Dialog를 닫아 입력창에 포커스를 복원한다. 인증 결과나 명령 응답으로 스레드 상태를 덮어쓰지 않는다.
- 재연결 실패는 로그인 실패로 취급하지 않는다. 닫을 수 없는 Dialog 안에서 기존 재연결 동작을 제공해 복구할 수 있도록 한다.
- 인증 전 및 연결 준비 전 전송은 버튼과 제출 처리 양쪽에서 차단한다. 인증 및 재연결로 자동 전송하거나 입력을 비우지 않는다.
- 한국어·영어, 밝은·어두운 테마 및 좁은 창을 지원한다. 공통 Dialog에는 일반적인 닫기 버튼 표시 옵션만 추가하며 인증 상태는 feature에 둔다.

## Testing Decisions

기존 App 통합 테스트를 주 경계로 사용한다. 실제 인증 대신 기존 Tauri 명령 mock과 제어 가능한 비동기 결과를 사용한다.

자동 진입, 닫기 버튼 없음, Escape·외부 클릭 차단, 전송 차단, 지원되지 않는 방법 제외, 키보드 선택, 오류·재시도·빈 목록, 명시적 인증 취소, 중복 시작 방지, 취소 후 늦은 결과 무시, 에이전트별 진행 공유, 초안·첨부 보존, 구독/명령 재연결 실패 및 복구, 성공 후 입력창 포커스를 검증한다. 외부 탐색 회귀는 modal 배경을 사용자 클릭으로 조작하지 않고 탐색 이벤트로 시뮬레이션한다.

## Out of Scope

백엔드 API, 데이터베이스 스키마, 인증 프로토콜 및 자격 증명 저장 변경, 새 UI 라이브러리, 에이전트 관리 화면 개편, README 변경은 포함하지 않는다.

## History

- 최초 구현은 명시적 Sign in 진입 버튼과 닫을 수 있는 Dialog였다.
- 2026-10-02: 사용자가 의도한 UI/UX를 정정했다. 입력창 버튼을 제거하고 인증 필요 시 자동으로 열리는 닫을 수 없는 Dialog로 진행을 차단한다. 이 정정이 기존 명시적 진입·닫기·입력창 편집 요구사항을 대체한다.
