# 01: 스레드 오른쪽 프로젝트 패널과 탭 기반

**What to build:** 상위 spec.md에 따라 기본적으로 접힌 오른쪽 패널, 너비 조절과 스레드별 브라우저형 탭을 구현한다. 실제 파일·인터넷·Git 기능은 후속 feature로 연결한다.

**Blocked by:** None.

## Acceptance criteria

- [x] 헤더에서 패널을 열고 접으며 경계를 드래그·키보드로 조절할 수 있다.
- [x] 탭 생성·선택·닫기와 선택 탭의 가로 스크롤을 제공한다.
- [x] 기본 탭 하나를 제공하고 마지막 탭을 닫아도 새 기본 탭으로 교체하여 최소 한 개를 유지한다.
- [x] 스레드별 독립 상태와 접기·화면 전환 후 콘텐츠·너비 유지를 제공한다.
- [x] 탭 닫기와 스레드 삭제 성공 시 콘텐츠를 정리한다.
- [x] 앱 계층에서 후속 feature 콘텐츠를 연결할 작은 public interface를 제공한다.
- [x] 한국어·영어와 라이트·다크 테마를 지원한다.
- [x] 프런트엔드 전체 검증과 프로덕션 빌드를 통과한다.
