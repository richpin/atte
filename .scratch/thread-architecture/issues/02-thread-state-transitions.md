# 02: 스레드 상태 변경 규칙을 스레드 module에 집중

**What to build:** 에이전트 연결·스레드 재개·실패·종료 시 스레드의 상태, 중단 표시, 인증 정보와 승인 요청이 기존과 일관되게 처리되도록 유지한다. 에이전트 실행 코드는 발생한 사실을 전달하고, 스레드 module은 그 사실을 스레드 상태에 반영하는 규칙을 책임지게 한다.

**Blocked by:** None (can start immediately).

Status: done

## 배경과 범위

현재 스레드 module은 오래된 실행의 변경을 거르는 generation 검사, 승인 요청 정리, 저장과 구독 발행을 담당한다. 그러나 에이전트 실행 코드는 변경 closure를 통해 스레드 상태·중단 여부·실패 원인·인증 상태를 직접 조합하고, 스레드 재개 결과와 안내도 반영한다. 하나의 상태 변경을 이해하려면 두 module의 규칙을 함께 읽어야 한다.

에이전트 실행 코드에서 직접 구성하는 연결 준비 완료, 스레드 재개 결과, 실패와 정상 연결 종료의 스레드 상태 변경을 스레드 module 내부로 모은다. 기존 generation 검사, 저장, 승인 요청 정리, 구독 발행과 함께 일관성을 유지한다. 에이전트 실행 코드는 프로토콜 교환, capability 선택, 실패 분류, 프로세스 수명과 공유 연결을 계속 담당한다.

현재의 스레드 module은 이미 중요한 보호 규칙을 제공한다. 이를 제거하지 않고 interface가 호출자에게 요구하는 스레드 내부 지식을 줄여 depth를 높인다. 작업 완료·취소·대기 메시지 진행 규칙은 기존 소유 위치와 동작을 유지하면서 변경 경로와의 상호작용을 검증한다. 구체적인 메서드 이름이나 개수는 현재 호출 경로를 확인해 정하며, 앞선 설명용 코드는 확정 설계가 아니다.

## Acceptance criteria

- [x] 에이전트 실행 코드가 연결 준비 완료·스레드 재개·실패·정상 연결 종료를 반영하기 위해 스레드의 가변 상태 전체를 전달받아 직접 조합하지 않는다. 해당 규칙은 스레드 module 안에서 책임진다.
- [x] 연결 준비 완료 시 원격 스레드 참조와 준비 상태를 유지한다. 스레드 재개는 기존 capability 선택을 따르며, 기록을 복원하는 경우와 맥락만 재개하는 경우의 본문·안내 표시 동작을 보존한다.
- [x] 실행·승인 대기·취소 중 실패하거나 종료된 스레드의 중단 표시, 실패 원인, 연결 상태와 인증 정보를 기존 규칙대로 반영한다. 인증 필요와 인증 성공의 공유 정보 갱신도 유지한다.
- [x] 교체되거나 종료된 실행의 늦은 변경이 새로운 실행의 상태를 덮어쓰지 않는다. 부분 응답 보존, 승인 요청 정리와 늦은 승인 응답 거부를 유지한다.
- [x] 상태 변경에 필요한 저장과 구독 발행이 기존 순서를 유지한다. 구독 revision과 답변 조각 순서, 저장 오류 표시를 보존하며 불필요한 중복 발행을 추가하지 않는다.
- [x] 정상 작업 완료에 따른 대기 메시지 진행과 취소·실패·인증 상실·스레드 재개 시 자동 전송 억제를 유지한다. 대기 메시지 제거 저장에 실패하면 전송하지 않는 기존 동작을 보존한다.
- [x] 공유 연결의 스레드 분리, 한 스레드의 취소·승인 대기가 다른 스레드를 막지 않는 동작, 에이전트 제거·앱 종료 시 프로세스 정리를 유지한다.
- [x] 기존 공개 스레드 interface와 Rust 에이전트 fixture를 통한 통합 테스트를 유지한다. 연결·재개·실패·취소·승인 정리·대기 메시지·오래된 실행 거부의 기존 검증을 확인하고, 변경으로 드러난 검증 공백만 보강한다. 내부 메서드 호출 순서만 고정하는 테스트는 만들지 않는다.
- [x] 관련 Rust 통합 테스트와 포맷·Clippy 검사를 통과한다. 변경된 설계를 설명하는 기존 문서가 있으면 함께 갱신하고 검증 결과를 Comments에 기록한다.

## 범위 밖

프런트엔드 동기화 리팩터링, Tauri 명령·이벤트 형식 변경, 데이터베이스 변경, 새 실패·재시도·대기 메시지 정책은 포함하지 않는다. 프로세스 공유 구조를 재설계하거나 새 런타임 trait·adapter 체계를 추가하지 않는다.
